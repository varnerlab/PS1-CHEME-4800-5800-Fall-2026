On the release page, scroll to Assets and select Source code (zip). Extract the archive before beginning. This problem set is supported with Julia 1.12.7.

The starter code is intentionally incomplete, so the tests will fail initially. Complete the requested work in the src directory. Do not modify the supplied tests, data, or submission checker to make an incomplete solution appear to pass.

Check your work

From the extracted problem-set folder, run:

julia --startup-file=no check_submission.jl

The checker runs the public tests and creates MANIFEST.txt. It does not upload anything to Canvas.

Submit to Canvas

  1. Zip the entire problem-set folder after running the checker.
  2. Rename the archive to CHEME-4800-5800-PS1-<your netid>.zip.
  3. Replace the complete <your netid> placeholder, including the angle brackets, with your actual NetID. For example: CHEME-4800-5800-PS1-abc123.zip.
  4. Upload the ZIP file to this Canvas assignment.

You must submit something by the initial deadline to participate in the infinite-revision policy. If you make no initial submission, the assignment score is 0 and later revisions will not be accepted for credit.

Revisions

After the initial deadline, eligible students may revise and resubmit PS1 through the end of the semester. Return to this same Canvas assignment, select New Attempt, and upload the revised ZIP file.

Canvas may label these revisions “late.” That is expected and does not create a penalty under the infinite-revision policy. Each revision will be graded, and the highest score earned will be retained.

Collaboration and academic integrity

Submit independent work. You may discuss the problem set with classmates, but you may not share code or solutions directly. You may use Julia documentation, AI tools, and internet resources, but you remain responsible for understanding and explaining everything you submit.

The reference solution will be released after the initial deadline. You may consult it to understand mistakes and debug your work, but your revision must remain your own implementation. Copying, lightly renaming, or mechanically reformatting reference-solution code does not constitute independent work and may trigger an academic-integrity review.
